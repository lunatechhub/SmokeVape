Image assets. This folder is the ONLY place images live. `dist/` is build
output generated by `npm run build` — never copy images into it by hand.

Shared images (every shop) are referenced from src/data/shared.js. Per-shop
photos live in a folder named after the tenant key and are referenced from
that shop's src/data/tenants/<key>.js through `images`. To swap a photo, drop
the new file in using the same filename and nothing in the code changes. If
the new file has a different extension or different pixel dimensions, update
the matching `src` / `width` / `height` in the data file to match — a path
that does not match a real file on disk is a broken image on the page.

Conventions
  products/    shared. Fitted with object-fit: contain into a 1:1 card — a
               square cutout on white or transparent looks best, but any
               ratio works
  categories/  shared. Cropped with object-fit: cover to 2:1 (3:2 from 768px up)
  <tenant>/    per shop: hero.jpg, storefront.jpg, interior.jpg, cropped with
               object-fit: cover to their frames
  favicon.svg  icon, referenced from index.html

Filenames are the slugged product name only — no numeric prefix, no puff
count, no flavour.

The hero photo wants a wide, bright, daylit shot of the storefront or the
product wall. The frame is 3:2 below 1024px and fills the full copy-column
height on desktop (object-fit: cover), so a landscape source crops best and a
1920x1280 file is the safe default. Swapping it is a drop-in at the same path
— update width/height in the tenant file to match.
